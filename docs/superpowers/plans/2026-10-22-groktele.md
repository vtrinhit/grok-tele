# GrokTele — Implementation plan

Spec: `docs/superpowers/specs/2026-10-22-groktele-design.md`. Python 3.13, venv `.venv`.

1. Skeleton: `pyproject.toml`, `.gitignore`, `.env.example`, `accounts.example.yaml`, `run.bat`.
2. `config.py`: đọc `.env` + `accounts.yaml`, `save_account`, `parse_proxy`. Test: proxy parse, upsert account.
3. `db.py`: schema jobs/accounts, create/dedupe/claim/requeue/finish/cancel/retry/reset_running/stats. Test từng hàm.
4. `chat.py`: `BotMessage`, `ChatEvent`, `BotChat` protocol, `TelethonChat`.
5. `bot_driver.py`: `classify`, `find_button`, `run_job`, `check_status`, lỗi `RetryableError/BotMaintenance/AccountExpired`.
   Test với `tests/fake_bot.py` (FakeChat mô phỏng bot thật).
6. `worker.py` + `manager.py`: vòng lặp tài khoản, xử lý lỗi theo bảng spec §5, health check, cancel.
7. `api.py` + `app.py`: route kiểu MultiKit, auth tùy chọn, lifespan khởi động manager.
   Test: luồng job qua HTTP, 409, cancel, retry, batch, accounts, stats.
8. Tương thích ReelFB: chạy `ReelFB_Studio/backend/services/multikit.py` thật vào server GrokTele (test tự skip nếu không có file).
9. `cli.py`: login / import-session / serve / status / pause / resume / try.
10. README tiếng Việt: cài đặt, login, chạy, nối ReelFB, autostart, xử lý sự cố.
